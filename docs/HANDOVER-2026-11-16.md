## 6. 未解决问题（按优先级）

### 6.1 显示卡顿：合成器只提交 3 帧后停摆（最高优先级）
证据（boot-present6.log）：
- swap accepted=1 约 3 次，present copied frame 1/2/3 之后无任何新 swap；
- PROC[1] backboardd ... w16（backboardd 等 16 个端口）；
- 系统仍活着（PROC/KNOTE/UIT 持续输出）⇒ swap 完成/唤醒链路停止，不是渲染慢。
下一步：在交换生命周期（validate→kick→copy→retire→wakeup）加计数打印（组件源 NativeLegacyDisplay.cpp），
定位停止点；重点检查 retireSwap/activateOnlyPendingSwap/completeCurrentSwap 与 work-loop 唤醒。

### 6.2 显示撕裂：单缓冲 + 无 fence 翻转
官方文档（/zh/porting/display）给出的正解：直接扫描输出 dpu-scanout=2，双缓冲 flip + latch，并等 GPU fence 再翻转。
仓库里已有：
- NativeLegacyDisplay 直接扫描输出实现（sheng-dpu-scanout=2，VIG0/VIG1 + CTL flush + latchTimer）；
- KonaUfs 显示 SMMU bank 实现（dpu-scanout=1，native_ufs_dpu_map 等）。
待验证：boot-dpu.img（args 988B，含 dpu-scanout=1 sheng-dpu-scanout=2）尚未刷机；
若 0xae01000/DPU 偏移与 SM8250 不匹配，DPUDBG 日志会显示 UFS bank / MDP 映射 / flip / latch 中哪一步失败，
再按 SM8250 DPU 手册适配常量（kVig、kCtlFlush、kBootIova、kBootStride）。

### 6.3 触控
已修（静默释放）未真机验证；历史日志显示 up 事件长期为 0，且芯片可能持续上报幽灵位置；
若修复后仍异常，需要原始事件字节级调试（ts_handle_events 加受限 raw dump）。

### 6.4 GPU 用户态能力
当前 v6 addon（2026-11-13 构建）GPU: addon files=6、Metal 客户端可用，但不含 GpuScanoutClient（GPU 呈现交接），
旧插件也没有新 plugin 源码功能。若要走 GPU 呈现/加速，需要在 macOS 上重建插件
（build-turnip-darwin.py + build-adreno-metal-plugin.py + make-gpu-addon.py + make-owner-trust-bundle.py），
并接入 CI（目前未实现）。

## 8. 已知坑 / 注意事项

1. args ≤ 1000 字节（DarwinBoot 合并命令行）；GPU/DPU 调试参数放不下时先删不必要项。
2. payload 有改动必须重建 boot image（payload.img 是 ramdisk，不是单独 flash）。
3. console 静音：默认无 offline-legacy-console=1 时屏幕无文字，同时串口日志会大幅减少；调试需加回该参数。
4. WSL /mnt 上的 mcopy 可能挂起（本会话遇到）；在 /tmp（ext4）内完成 FAT 操作，
   最终镜像再用 PowerShell 从 \\wsl.localhost\Ubuntu-22.04\tmp\... 拷回 Windows。
5. tree 同步：改 kits/、package/、drivers/ 后不一定是编译源；确认 out/.../tree/ 内文件已更新。
6. CI 的 kernel 必须打 AMFI 补丁（patch-amfi-nopmgr.py、patch-amfi-trustcache-gate.py），否则 UEFI 返回菜单。
7. PAT/密钥不入库：本会话曾出现 tools/push-evidence.sh 内嵌 PAT，已删除；任何脚本禁止提交 token。
8. 崩溃恢复：设备无 fastboot 时，长按电源 12 秒；再音量上+电源进 fastboot。

## 9. 下一步建议（按优先级）

1. 刷 boot-dpu.img 验证 DPU 直接扫描输出：看 DPUDBG 输出（ufs_state、direct enabled、flip、latch、fallback 原因）。
   若 UFS bank 失败 → 先修 KonaUfs dpu-scanout=1；若 MDP 偏移不对 → 按 SM8250 DPU 手册改
   kVig/kCtlFlush/kBootIova/kBootStride。
2. 修 swap 3 帧停摆：在组件 NativeLegacyDisplay.cpp 的 validate/kick/retire 加计数；修复后帧才能持续流动，
   卡顿/触控/GPU 呈现都依赖它。
3. 触控 release 真机验证（滑动/点按后日志出现 released after）。
4. GPU 呈现交接：macOS CI 重建含 GpuScanoutClient 的插件（turnip + metal plugin + addon + owner trust），
   再配 sheng-fb-gpu=1 与 DPU scanout 双缓冲。
5. CI 收尾：[payload.runtime] 配置、runtime/GPU 构建步骤、per-file 矩阵与缓存。
